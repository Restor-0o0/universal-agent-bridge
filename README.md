# Universal Agent Bridge

Приложение для управления локальными AI-агентами с компьютера и Android-телефона.
Один Host автоматически подключает Codex, Claude Code и OpenCode, поэтому команды
и пути к CLI вручную указывать не нужно.

## Возможности

- Codex, Claude Code и OpenCode через единый интерфейс.
- До 100 вкладок в разных проектах и до 20 одновременно работающих агентов.
- Продолжение сохранённых сессий, автомод, approvals, остановка и переименование.
- Просмотр с телефона уже запущенной терминальной сессии Codex или Claude.
- Выбор рабочей папки через проводник компьютера.
- Уведомления и повторяющийся сигнал, когда агенту нужна помощь.
- Один локальный Router для Windows и телефона без ручного ввода адресов и ключей.
- Несколько изолированных пользователей на одном Router: отдельные пароли и список доступных компьютеров.
- Подключение через VPS для удалённого доступа.
- Русский и английский интерфейс, светлая и тёмная темы.

## Установка

Готовые пакеты находятся в [`dist/`](dist/):

- **Windows:** запустите `AgentBridge-Windows-x64-0.1.0.exe`.
- **Android:** установите `AgentBridge-Android-debug-0.1.0.apk`.
- **Linux:** установите `AgentBridge-Linux-amd64-0.1.0.deb`:

```bash
sudo apt install ./AgentBridge-Linux-amd64-0.1.0.deb
```

На компьютере должен быть установлен и авторизован хотя бы один агент:
`codex`, `claude` или `opencode`.

## Быстрый старт

1. Запустите AgentBridge на компьютере.
2. Нажмите **Запустить один Router** — Relay и Host запустятся автоматически.
3. Создайте вкладку, выберите агента и папку проекта.
4. Напишите задачу агенту.

Чтобы подключить Android по USB:

1. Включите отладку по USB и подключите телефон.
2. В Desktop нажмите **Подключить телефон по USB**.
3. Откройте AgentBridge на телефоне — адрес и ключи подставятся автоматически.

Чтобы посмотреть Codex или Claude, уже запущенный в терминале, откройте на
телефоне **Сессии из терминала → Найти текущую сессию → Смотреть**. После
завершения текущего шага сессию можно продолжить в обычной вкладке AgentBridge.

## Сборка из исходников

Требуются JDK 17 и Android SDK. Полная сборка пакетов на Windows:

```powershell
.\scripts\build-release.ps1
```

Для запуска проекта из исходников:

```powershell
.\gradlew.bat :desktopApp:run
```
