# Несколько пользователей на одном Router

Один Relay может обслуживать несколько людей и несколько Host-компьютеров. Каждый
пользователь получает отдельное пространство, пароль Router и ключ шифрования.
Устройства из разных пространств не видят друг друга и не могут обмениваться
сообщениями, даже если у них совпадают имена компьютеров или сессий.

## Добавить пользователя на VPS

После установки свежего Relay выполните:

```bash
sudo /opt/agent-bridge/add-workspace.sh alex
```

Скрипт создаст случайные `PASSWORD` и `KEY`, перезапустит Relay и покажет данные,
которые нужно передать владельцу пространства. Повторите команду с другим именем
для каждого пользователя. Конфигурации сохраняются с правами `600` в
`/etc/agent-bridge/workspaces/`.

## Подключить Host-компьютер

В Windows VPS Client укажите URL, имя пространства, пароль, ключ и понятный ID
компьютера. Эти значения сохраняются в `%APPDATA%\AgentBridge\vps-connection.conf`.

При ручном запуске Host используются переменные:

```text
AGENT_BRIDGE_RELAY_URL=https://agents.example.com
AGENT_BRIDGE_WORKSPACE=alex
AGENT_BRIDGE_DEV_TOKEN=<PASSWORD>
AGENT_BRIDGE_DEV_KEY=<KEY>
AGENT_BRIDGE_HOST_ID=alex-laptop
```

## Подключить телефон

1. Введите URL Relay, пространство, пароль Router и ключ шифрования.
2. Нажмите **Показать доступные компьютеры**.
3. Выберите нужный Host из списка.
4. Нажмите **Подключиться**.

Новый код подключения содержит пять частей:

```text
url|workspace|password|key|host-id
```

Старый трёхчастный код `url|token|key` продолжает работать для пространства
`default` и компьютера `host`.

## Изоляция

- список Host доступен только после проверки пароля пространства;
- WebSocket регистрируется внутри одного пространства;
- Relay ищет получателя только внутри пространства отправителя;
- одинаковые `host-id` разрешены в разных пространствах;
- содержимое команд и ответов остаётся зашифрованным общим для пространства ключом.
