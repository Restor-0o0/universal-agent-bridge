# Просмотр и перенос терминальной сессии

Agent Bridge умеет находить Codex и Claude Code, которые были запущены обычной
командой в терминале Host-компьютера. Session ID и путь к файлу истории вводить
не нужно.

## Как открыть с телефона

1. Запустите Codex или Claude Code в обычном терминале ноутбука.
2. Подключите Desktop и Android к одному Router.
3. На телефоне откройте **Сессии из терминала**.
4. Нажмите **Найти текущую сессию**, затем **Смотреть** у нужного проекта.

Host читает append-only историю агента и передаёт её через тот же зашифрованный
канал, что и управляемые вкладки. Исходный процесс продолжает работать. Экран
обновляется примерно раз в секунду, когда файл истории изменяется.

Пока исходный агент выполняет шаг, подключение работает только для просмотра.
После минуты без новых событий появляется **Продолжить в Agent Bridge**. Кнопка
создаёт обычную вкладку и вызывает штатный resume выбранного harness. После
переноса не отправляйте новые сообщения в старом терминале: Codex и Claude Code
поддерживают resume сохранённой сессии, но обычный терминальный процесс не
предоставляет публичный канал для двух одновременных управляющих клиентов.

OpenCode устроен иначе: его TUI является клиентом локального HTTP-сервера и
официально поддерживает несколько клиентов через `opencode attach`. Текущая
версия Agent Bridge продолжает управлять OpenCode через встроенный ACP adapter;
подключение к произвольно запущенному OpenCode server будет отдельным transport,
когда Host сможет безопасно получить его адрес и credentials.

## Безопасность

- Host открывает истории только из `~/.codex/sessions` и `~/.claude/projects`.
- Клиент не может передать произвольный путь к файлу.
- Просмотр не отправляет сигналы и команды терминальному процессу.
- В UI передаётся ограниченный хвост истории, а не весь большой JSONL-файл.
- Resume блокируется, пока история недавно обновлялась.
